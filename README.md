# 📡 Dekal Transmitter

Серверный **NeoForge** мод для Minecraft, заменяющий проверку сессий Mojang на локальную базу аккаунтов (SQLite) со встроенным HTTP-сервером авторизации и раздачи файлов для лаунчера.

> [!NOTE]
> Мод работает **только на стороне сервера** и перехватывает этап верификации шифрования (`handleKey`), позволяя серверу безопасно работать в режиме защиты сессий без обращения к `sessionserver.mojang.com`.

---

### 🚀 Как это работает

```text
Launcher / Client ──► REST API (:25999) ──► SQLite (accounts.db)
                                                   ▲
Minecraft Client ──[ Login Handshake ]──► MixinServerLogin (Dekal Transmitter)
```

1. Лаунчер регистрирует/авторизует игрока через встроенный REST API и сохраняет сессию в SQLite.
2. Перед подключением клиент отправляет токен и хеш сессии (`digest`) в эндпоинт `/session/minecraft/join`.
3. При входе на сервер `MixinServerLogin` сверяет `digest` напрямую в памяти и бесшовно пускает игрока в игру.

> [!IMPORTANT]
> Для подключения к серверу игрокам **обязательно** требуется клиентский мод **[Dekal Relay](https://github.com/ВАШ_АККАУНТ/dekal-relay)**, который перенаправляет хэндшейк клиента на встроенный API Transmitter'а.

### 🔌 Совместимость

> [!TIP]
> **Simple Voice Chat** работает **из коробки**. Voice Chat использует собственный независимый UDP-порт и берет уже авторизованные сессии игроков без каких-либо конфликтов.

---

### ⚙️ Сборка

* Требуется **Java 21+** и **NeoForge 26.1.2+**.

```bash
./gradlew build
```
Готовый мод появится в `build/libs/`.

---

> [!WARNING]
> Порт встроенного веб-сервера (`25999`) и путь к раздаваемым файлам лаунчера (`launcher/`) настраиваются в [Config.java](src/main/java/btxds/dekal/transmitter/Config.java). Не забудьте открыть этот TCP-порт в панели хостинга или файрволе!
